  ---
  🔧 Troubleshooting

  Issue: Motor doesn't move at all

  Symptoms: Motor feels stiff (locked) but doesn't rotate

  Checks:
  1. Verify 12V power:
    - Use multimeter on TMC2209 VM+ and GND
    - Should read ~12V DC
  2. Check EN pin:
    - Serial should say "Motor enabled!"
    - EN pin should be LOW (0V)
    - Measure EN pin with multimeter: should be 0V
  3. Verify STEP signal:
    - Serial shows "Rotating CLOCKWISE..."
    - Measure GPIO 25 with multimeter set to voltage
    - Should flicker between 0V and 3.3V
  4. Check common ground:
    - Verify ESP32 GND connects to TMC2209 GND
    - Measure resistance: should be ~0Ω
  5. Test with different speed:
  Edit src/main.cpp, change:
  #define STEP_DELAY_US  1000   // Try 2000 (slower) or 500 (faster)
  5. Rebuild and upload

  ---
  Issue: Motor vibrates/buzzes but doesn't rotate

  Symptoms: Motor shakes or buzzes in place, doesn't turn

  Cause: Motor coil wires are incorrect

  Fix:
  1. Unplug 12V power
  2. Swap one coil pair on TMC2209:
    - Swap A1 ↔ A2, OR
    - Swap B1 ↔ B2
  3. Plug in 12V power and test again

  If still vibrating:
  - Verify you correctly identified coil pairs (re-measure with multimeter)
  - Try swapping the other coil pair

  ---
  Issue: Motor rotates wrong direction

  Symptoms: Motor rotates, but CW when it should be CCW (or vice versa)

  Fix Option 1 - Swap direction in code:
  Edit src/main.cpp:
  void set_direction(bool clockwise) {
      digitalWrite(DIR_PIN, clockwise ? LOW : HIGH);  // Reversed!
      delayMicroseconds(5);
  }

  Fix Option 2 - Swap one coil physically:
  - Swap A1 ↔ A2, OR
  - Swap B1 ↔ B2

  ---
  Issue: Motor rotates but doesn't return to start position

  Symptoms: Motor drifts, doesn't return to same position each cycle

  Likely causes:
  - Steps are being missed (too fast)
  - Motor skipping steps under no load (unusual)

  Fix:
  1. Slow down movement:
  #define STEP_DELAY_US  2000   // Slower
  2. Add load to motor:
    - Gently hold motor shaft with fingers (light resistance)
    - Should still rotate smoothly
  3. Check for mechanical binding:
    - Motor shaft should spin freely by hand when powered off

  ---
  Issue: Motor gets very hot

  Symptoms: Motor too hot to touch after 1-2 minutes

  Causes:
  - Current limit too high on TMC2209
  - Motor coils shorted

  Immediate action:
  - Unplug 12V power
  - Let motor cool

  Fix:
  - This is normal for TMC2209 at full current
  - We'll adjust current limit in Phase 2 (UART configuration)
  - For now: Motor warm/hot is OK, just don't run continuously

  ---
  Issue: TMC2209 gets very hot

  Symptoms: Heatsink too hot to touch (<1 second)

  Immediate action:
  - Unplug 12V power

  Checks:
  1. Verify heatsink is installed on TMC2209 chip
  2. Check for short between VM+ and GND (should be >100Ω)
  3. Verify motor coils are correct (measure resistance)

  Temporary fix:
  - Add cooling fan pointed at TMC2209
  - Reduce run time (30 seconds on, 30 seconds off)

  Permanent fix:
  - Phase 2 will configure current limit via UART

  ---
  Issue: Motor moves erratically

  Symptoms: Sometimes moves, sometimes doesn't, or skips randomly

  Causes:
  - Loose wire connections
  - Bad common ground
  - Noise on signal lines

  Fix:
  1. Check all connections:
    - Tighten screw terminals
    - Verify jumper wires are fully inserted
    - Wiggle wires while running - should not affect movement
  2. Shorten jumper wires:
    - Use shortest possible wires for STEP/DIR/EN
    - Route signal wires away from power wires
  3. Add bypass capacitor (advanced):
    - 100nF ceramic cap between ESP32 3.3V and GND

  ---
  Issue: Serial monitor shows garbled text

  Cause: Wrong baud rate

  Fix:
  - Set serial monitor to 115200 baud
  - In PlatformIO: Click gear icon in monitor, select 115200

  ---
  Issue: ESP32 keeps resetting

  Symptoms: Serial output shows boot messages repeatedly

  Causes:
  - Power supply issue
  - Brownout detection triggered
  - Bad USB cable

  Fix:
  1. Try different USB port (use USB port on computer, not hub)
  2. Try different USB cable
  3. Disconnect 12V power and test ESP32 alone

  📊 Performance Testing

  Once motor is running reliably, try these tests:

  Test 1: Speed Variation

  Edit STEP_DELAY_US and observe:

  | STEP_DELAY_US | Speed (RPM) | Behavior                         |
  |---------------|-------------|----------------------------------|
  | 2000          | ~9.4        | Very slow, easy to see each step |
  | 1000          | ~18.8       | Slow, smooth (default)           |
  | 500           | ~37.5       | Medium speed                     |
  | 200           | ~93.8       | Fast                             |
  | 100           | ~187.5      | Very fast                        |

  Note: At <500us, motor may vibrate or stall (no load). With split-flap load, slower speeds will be needed.

  ---
  Test 2: Full Revolution

  Change test parameters to complete a full rotation:

  #define TEST_STEPS  3200   // Full revolution (200 steps × 16 microsteps)
  #define PAUSE_MS    2000   // 2 second pause

  Expected:
  - Motor makes exactly 1 full rotation
  - Returns to exact starting position
  - Takes ~3.2 seconds per rotation (at 1000us delay)

  ---
  Test 3: Direction Control

  Verify both directions work:

  // In loop(), test continuous rotation:
  move_steps(100, true);   // CW
  delay(500);
  move_steps(100, true);   // CW again (should continue same direction)
  delay(500);
  move_steps(100, false);  // CCW
  delay(500);
  move_steps(100, false);  // CCW again

  ---
  Test 4: Enable/Disable

  Test EN pin control:

  enable_motor();
  move_steps(200, true);
  disable_motor();   // Motor should release (can be turned by hand)
  delay(2000);
  enable_motor();    // Motor locks again
  move_steps(200, false);

  Expected:
  - When disabled: motor shaft spins freely by hand
  - When enabled: motor shaft feels stiff (locked)
